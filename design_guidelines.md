# GoDo Website Design Guidelines

## Design Approach
**Reference-Based Approach**: Drawing inspiration from modern gig economy platforms like Uber, TaskRabbit, and Fiverr, combined with Telegram's clean messaging aesthetic. The design emphasizes speed, accessibility, and immediate action.

## Core Design Elements

### Color Palette
**Primary Colors:**
- Brand Blue: 220 85% 55% (modern, trustworthy)
- Success Green: 145 70% 50% (earning/completion)
- Accent Purple: 270 80% 65% (premium feel)

**Supporting Colors:**
- Dark Mode: 220 15% 12% (backgrounds)
- Light Gray: 220 10% 95% (sections)
- Warning Orange: 25 85% 60% (urgency)

### Typography
- **Primary**: Inter (Google Fonts) - clean, modern readability
- **Accent**: Outfit (Google Fonts) - for headers and CTAs
- **Sizes**: Large headers (3xl-5xl), readable body (lg-xl)

### Layout System
**Spacing Units**: Consistent use of Tailwind units 4, 8, 16, 24 for predictable rhythm
- Sections: py-16 or py-24
- Component spacing: gap-8, space-y-8
- Padding: p-8, px-8, py-4

### Component Library
**Core Elements:**
- Large gradient CTA buttons with rounded corners
- Icon-text combinations using Heroicons
- Card-based layouts with subtle shadows
- Simple 3-step process visualization
- Split-screen layouts for dual audiences

**Navigation:**
- Clean header with logo and 3 main sections
- Sticky navigation on mobile
- Large touch targets (min 44px)

**Forms/CTAs:**
- Prominent dual buttons in hero (Worker/Employer)
- Single-action CTAs per section
- Telegram-style button styling

### Modern Effects
- Subtle gradient backgrounds
- Smooth scroll animations (minimal)
- Hover states with gentle scaling
- Soft drop shadows and blurred backgrounds for outline buttons over images

## Images
**Hero Image**: Large background image showing diverse workers (construction, beauty, delivery) in action - modern, energetic photography with gradient overlay

**Section Images**: 
- Icon illustrations for 3-step process
- Small profile photos for testimonials/examples
- Telegram bot interface screenshots

## Key Principles
1. **Mobile-First**: Target audience primarily uses mobile devices
2. **Immediate Value**: Every section answers "What's in it for me?"
3. **Conversational Tone**: Simple, friend-to-friend language
4. **Speed Emphasis**: Visual cues reinforcing "today," "now," "fast"
5. **Telegram Integration**: Visual consistency with Telegram's design language

## Page-Specific Notes
- **Homepage**: Balanced for both audiences with clear path splitting
- **Employer Page**: Professional pain-point focused design with urgency indicators
- **Worker Page**: Aspirational design emphasizing quick earnings and flexibility
